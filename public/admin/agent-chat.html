Discovery settings
Runs on a cron (database/run_beacon_discovery.php): searches the keywords below via Serper, runs new results through Beacon, and sends you a digest (Slack and/or email, whichever is configured under Settings) of anything qualified — Beacon can't post back to Reddit/X/LinkedIn itself, so this is a digest for you to act on, not an auto-reply. Serper only returns a short snippet per result, not the full post, so treat qualified results as a lead worth opening, not a final verdict.
Google ranks old threads highest for evergreen phrases — without this, sweeps return posts from years ago that nobody is hiring from. Tighter is fewer but fresher.
Skips the pending_review hold for leads scoring below 70 confidence — every qualified lead reaches the pipeline (and its automation) immediately, no approval click needed.
What discovery is costing

Serper bills 1 credit per search; every new result costs an AI call. Failed scores cost a call too and buy nothing — if that number is climbing, a provider is rate-limiting you.

LinkedIn Engagement Scraper
A second, higher-signal lead source: runs on a cron (database/run_beacon_apify_discovery.php) against the tracked profiles below, pulling each one's newest posts, then everyone who reacted to or commented on them — via Apify, an API key away in Settings -> Integrations. Every engager is scored on ICP fit (their own headline, not the post) and joins the same qualified-lead queue and digest as regular Beacon discovery. Needs an Apify API key configured, plus one actor for "get a profile's posts" and one for "get a post's reactions/comments" — pick any from the Apify Store and paste their actor IDs below.
Suggested: harvestapi/linkedin-profile-posts — returns a profile's newest posts, matches the default input template below.
Suggested: apimaestro/linkedin-post-comments-replies-engagements-scraper-no-cookies — returns commenters (with their reaction counts); doesn't surface people who only reacted without commenting.
Advanced: actor input templates
Every actor on Apify expects slightly different input field names — these templates are sent as-is, with {{PROFILE_URL}}/{{POSTS_LIMIT}} and {{POST_URL}}/{{ENGAGERS_LIMIT}} substituted in. Check your chosen actor's own documentation for its real input schema and adjust these to match — the defaults are a starting guess, not a guarantee.
What the LinkedIn scraper is costing

Each tracked profile costs at least one Apify call (posts), plus one more per new post found (engagers). Every new engager scored costs an AI call.
