ElevenLabs WhatsApp (voice + chat)

Set up the WhatsApp number in ElevenLabs' Agents dashboard first (connect it to a Meta Business Portfolio, enable voice calls). Two different auth styles below — the init/tool webhooks use a secret you create and paste into ElevenLabs as a custom header; the post-call webhook uses a secret ElevenLabs generates that you paste in here instead.

Conversation initiation webhook: https://princecaleb.dev/api/v1/whatsapp/elevenlabs-init — add custom header X-ElevenLabs-Secret set to this value.
Tool webhooks: in the agent's Tools section (separate from the webhooks above), add one webhook tool per capability, each pointing at https://princecaleb.dev/api/v1/whatsapp/elevenlabs-tool?tool_name=check_availability (swap the tool_name value per tool — e.g. book_appointment, log_inquiry, get_site_info), same custom header as above. Optionally add &session_token={{session_token}} to the URL so bookings land in the right conversation thread.
Post-call webhook: https://princecaleb.dev/api/v1/whatsapp/elevenlabs-post-call. When you add this URL in the agent's post-call webhook settings, ElevenLabs generates its own signing secret and shows it once — paste that value here (don't invent one, and don't add a custom header for this one).

Only a Google account whose email matches your admin login email can sign in.
